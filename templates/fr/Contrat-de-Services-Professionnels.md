# Contrat de Services Professionnels

1. <span class="header_2">Services</span>
    1. <span class="header_3">Prestation de Services.</span>  Le <span class="keyterms_link">Client</span> ou ses Filiales peuvent conclure des BdT avec le <span class="keyterms_link">Prestataire</span>. Le <span class="keyterms_link">Prestataire</span> exécutera les Services tels que détaillés dans un BdT applicable. Chaque BdT, conjointement avec les Conditions Clés et les Conditions Générales, constitue un accord distinct. Le <span class="keyterms_link">Prestataire</span> respectera les <span class="keyterms_link">Politiques du Client</span>, le cas échéant.
    2. <span class="header_3">Coopération.</span>  Le <span class="keyterms_link">Client</span> coopérera raisonnablement avec le <span class="keyterms_link">Prestataire</span> pour permettre l'exécution des Services. Le <span class="keyterms_link">Prestataire</span> n'est pas responsable de son incapacité à exécuter les Services causée par le manquement du <span class="keyterms_link">Client</span> à coopérer. Le <span class="keyterms_link">Prestataire</span> fournira son propre équipement et ses propres outils.
    3. <span class="header_3">Ordres de Modification.</span>  Le <span class="keyterms_link">Prestataire</span> ou le <span class="keyterms_link">Client</span> peut modifier tout BdT en concluant un Ordre de Modification. Si une partie demande un Ordre de Modification, l'autre partie examinera et considérera les modifications proposées de bonne foi. Cependant, un Ordre de Modification ne sera contraignant qu'après accord écrit du <span class="keyterms_link">Prestataire</span> et du <span class="keyterms_link">Client</span>.
    4. <span class="header_3">Acceptation.</span>  Si, selon le BdT, les <span class="sow_link">Livrables</span> sont soumis à cette section, le <span class="keyterms_link">Client</span> sera réputé avoir approuvé un <span class="sow_link">Livrable</span> s'il ne le rejette pas dans le <span class="sow_link">Délai de Rejet</span>. En cas de rejet, le <span class="keyterms_link">Client</span> doit notifier le <span class="keyterms_link">Prestataire</span> par écrit avec des détails raisonnables. Le <span class="keyterms_link">Prestataire</span> corrigera le problème et soumettra à nouveau le <span class="sow_link">Livrable</span> dans le <span class="sow_link">Délai de Nouvelle Soumission</span>.
    5. <span class="header_3">Sous-traitants.</span>  Le <span class="keyterms_link">Prestataire</span> ne peut faire appel à des Sous-traitants pour exécuter les Services qu'avec l'autorisation préalable du <span class="keyterms_link">Client</span>. Cependant, le <span class="keyterms_link">Prestataire</span> peut utiliser ses Filiales sans autorisation préalable.
    6. <span class="header_3">Obligations du Client.</span>  Le <span class="keyterms_link">Client</span> respectera les <span class="sow_link">Obligations du Client</span>, le cas échéant.
2. <span class="header_2">Propriété Intellectuelle</span>
    1. <span class="header_3">Livrables.</span>  À l'exception des Matériaux Préexistants et des Matériaux Tiers, le <span class="keyterms_link">Prestataire</span> cède au <span class="keyterms_link">Client</span> tous les droits, titres et intérêts dans les <span class="sow_link">Livrables</span> (le cas échéant) au <span class="sow_link">Moment de la Cession</span>.
    2. <span class="header_3">Matériaux du Client.</span>  Le <span class="keyterms_link">Prestataire</span> peut copier, afficher, modifier et utiliser les Matériaux du Client uniquement dans la mesure nécessaire pour fournir les Services.
    3. <span class="header_3">Matériaux Préexistants.</span>  Dans la mesure où le <span class="keyterms_link">Prestataire</span> intègre des Matériaux Préexistants dans les <span class="sow_link">Livrables</span>, le <span class="keyterms_link">Prestataire</span> accorde au <span class="keyterms_link">Client</span> une licence non exclusive, non transférable, perpétuelle, irrévocable et mondiale pour utiliser les Matériaux Préexistants uniquement dans la mesure nécessaire à l'utilisation des <span class="sow_link">Livrables</span>.
    4. <span class="header_3">Matériaux Tiers.</span>
        a. Le <span class="keyterms_link">Prestataire</span> ne peut intégrer des Matériaux Tiers dans les <span class="sow_link">Livrables</span> que si le BdT l'autorise et avec l'autorisation écrite du <span class="keyterms_link">Client</span>.
        b. Le <span class="keyterms_link">Prestataire</span> est responsable d'obtenir tous les droits, licences et autorisations nécessaires pour utiliser les Matériaux Tiers qu'il se procure.
        c. Le <span class="keyterms_link">Client</span> est responsable d'obtenir tous les droits, licences et autorisations nécessaires pour les Matériaux Tiers qu'il se procure.
    5. <span class="header_3">Retours et Données d'Utilisation.</span>  Le <span class="keyterms_link">Client</span> peut transmettre des Retours au <span class="keyterms_link">Prestataire</span> qui peut les utiliser librement. Le <span class="keyterms_link">Prestataire</span> peut collecter et analyser les Données d'Utilisation.
    6. <span class="header_3">Réserve de Droits.</span>  Sauf pour la propriété des <span class="sow_link">Livrables</span>, les droits sur les Matériaux du Client et les droits sur les Matériaux Préexistants, aucune partie ne transfère de droits sur ses produits, données ou propriété intellectuelle.
3. <span class="header_2">Confidentialité et Sécurité</span>
    1. <span class="header_3">Données Personnelles.</span>  Si les parties ont conclu un <span class="keyterms_link">ATD</span>, chaque partie respectera ses obligations au titre de l'<span class="keyterms_link">ATD</span>, notamment le RGPD et la loi Informatique et Libertés.
    2. <span class="header_3">Sécurité.</span>  Le <span class="keyterms_link">Prestataire</span> respectera la <span class="keyterms_link">Politique de Sécurité</span>, le cas échéant.
4. <span class="header_2">Paiement et Taxes</span>
    1. <span class="header_3">Honoraires et Factures.</span>  Sauf indication contraire dans le BdT, tous les <span class="sow_link">Honoraires</span> sont libellés en euros et sont hors taxes. Sauf remboursement proratisé prévu, les <span class="sow_link">Honoraires</span> ne sont pas remboursables.
    2. <span class="header_3">Paiement.</span>  Le <span class="keyterms_link">Client</span> paiera au <span class="keyterms_link">Prestataire</span> les <span class="sow_link">Honoraires</span> et taxes de chaque facture en euros dans le <span class="sow_link">Délai de Paiement</span>.
    3. <span class="header_3">Taxes.</span>  Le <span class="keyterms_link">Client</span> est responsable de tous droits, taxes et prélèvements applicables aux <span class="sow_link">Honoraires</span>, y compris la TVA ou retenues à la source. Cependant, le <span class="keyterms_link">Client</span> n'est pas responsable de l'impôt sur les bénéfices du <span class="keyterms_link">Prestataire</span>.
    4. <span class="header_3">Contestation de Paiement.</span>  En cas de désaccord de bonne foi sur les montants facturés, le <span class="keyterms_link">Client</span> notifiera le <span class="keyterms_link">Prestataire</span> et paiera les montants non contestés à temps. Les parties s'efforceront de résoudre le différend dans un délai de 15 jours.
5. <span class="header_2">Durée et Résiliation</span>
    1. <span class="header_3">Durée.</span>  Le présent Accord débutera à la <span class="keyterms_link">Date d'Entrée en Vigueur</span> et se poursuivra jusqu'à 12 mois après la fin de la dernière <span class="keyterms_link">Durée du BdT</span>.
    2. <span class="header_3">Résiliation.</span>
        a. Chaque partie peut résilier le présent Accord ou un BdT immédiatement si l'autre partie (i) ne remédie pas à une violation matérielle dans les 30 jours suivant la notification ; (ii) viole matériellement d'une manière qui ne peut être rectifiée ; (iii) est dissoute ou cesse ses activités ; (iv) effectue une cession au profit de ses créanciers ; ou (v) fait l'objet d'une procédure collective qui se poursuit plus de 60 jours.
        b. Chaque partie peut résilier un BdT concerné immédiatement si un Événement de Force Majeure empêche le <span class="keyterms_link">Prestataire</span> de fournir les Services pendant 30 jours consécutifs ou plus.
        c. Chaque partie peut résilier le présent Accord pour quelque raison que ce soit s'il n'existe pas de BdT actif.
        d. Une partie doit notifier l'autre de la raison de sa résiliation.
    3. <span class="header_3">Effets de la Résiliation.</span>  À toute expiration ou résiliation :
        a. La résiliation de l'Accord entraîne automatiquement la résiliation de tous les BdT.
        b. Le <span class="keyterms_link">Prestataire</span> n'est plus tenu de fournir les Services.
        c. Chaque Destinataire restituera ou détruira les Informations Confidentielles du Divulgateur.
        d. Sauf résiliation par le <span class="keyterms_link">Client</span> pour faute, le <span class="keyterms_link">Prestataire</span> soumettra une facture finale.
        e. Sauf résiliation par le <span class="keyterms_link">Prestataire</span> pour faute, le <span class="keyterms_link">Prestataire</span> remboursera les <span class="sow_link">Honoraires</span> prépayés non utilisés.
6. <span class="header_2">Déclarations et Garanties</span>
    1. <span class="header_3">Mutuelles.</span>  Chaque partie déclare et garantit à l'autre : (a) avoir le pouvoir légal et l'autorité de conclure le présent Accord ; (b) être dûment constituée et en règle ; (c) respecter toutes les Lois Applicables ; et (d) respecter les <span class="keyterms_link">Garanties Supplémentaires</span>.
    2. <span class="header_3">Du Client.</span>  Le <span class="keyterms_link">Client</span> déclare et garantit au <span class="keyterms_link">Prestataire</span> que (a) l'utilisation des Matériaux du Client ne violera pas les droits de propriété intellectuelle de tiers ; et (b) il dispose de tous les droits nécessaires.
    3. <span class="header_3">Du Prestataire.</span>  Le <span class="keyterms_link">Prestataire</span> déclare et garantit au <span class="keyterms_link">Client</span> que : (a) il exécutera les Services de manière diligente, compétente et professionnelle ; (b) les <span class="sow_link">Livrables</span> ne violeront pas les droits de propriété intellectuelle de tiers ; (c) les <span class="sow_link">Livrables</span> seront conformes aux exigences du BdT ; et (d) il dispose de tous les droits nécessaires.
7. <span class="header_2">Exclusion de Garanties</span>
    1. Sauf pour les garanties de la Section 6, le <span class="keyterms_link">Prestataire</span> et le <span class="keyterms_link">Client</span> **excluent toutes autres garanties, expresses ou implicites, y compris les garanties implicites de qualité marchande, d'adéquation à un usage particulier, de titre et d'absence de contrefaçon**. Ces exclusions s'appliquent dans toute la mesure permise par les Lois Applicables.
8. <span class="header_2">Limitation de Responsabilité</span>
    1. <span class="header_3">Plafonds de Responsabilité.</span>  **S'il existe des <span class="keyterms_link">Réclamations Majorées</span>, la responsabilité totale et cumulée de chaque partie pour ces réclamations ne dépassera pas le <span class="keyterms_link">Montant Plafonné Majoré</span>. La responsabilité totale et cumulée de chaque partie pour toutes les autres réclamations ne dépassera pas le <span class="keyterms_link">Montant Plafonné Général</span>.**
    2. <span class="header_3">Exclusion de Dommages.</span>  **En aucun cas une partie ne sera responsable envers l'autre pour perte de bénéfices ou de revenus, ni pour dommages consécutifs, spéciaux, indirects, punitifs ou accessoires, dans toute la mesure permise par les Lois Applicables.**
    3. <span class="header_3">Exceptions.</span>  Les plafonds de la Section 8.1 ne s'appliquent pas aux <span class="keyterms_link">Réclamations Illimitées</span>. L'exclusion de dommages de la Section 8.2 ne s'applique pas aux <span class="keyterms_link">Réclamations Majorées</span> ni à une violation de la Section 11 (Confidentialité).
9. <span class="header_2">Indemnisation</span>
    1. <span class="header_3">Protection par le Prestataire.</span>  Le <span class="keyterms_link">Prestataire</span> indemnisera, défendra et garantira le <span class="keyterms_link">Client</span> contre toutes les <span class="keyterms_link">Réclamations Couvertes du Prestataire</span> faites par un tiers autre que le <span class="keyterms_link">Client</span> ou ses Filiales.
    2. <span class="header_3">Protection par le Client.</span>  Le <span class="keyterms_link">Client</span> indemnisera, défendra et garantira le <span class="keyterms_link">Prestataire</span> contre toutes les <span class="keyterms_link">Réclamations Couvertes du Client</span> faites par un tiers.
    3. <span class="header_3">Procédure.</span>  Les obligations de la Partie Indemnisatrice sont conditionnées au fait que la Partie Protégée notifie promptement chaque Réclamation Couverte, fournisse une assistance raisonnable et accorde le contrôle exclusif de la défense.
    4. <span class="header_3">Recours Exclusif.</span>  La présente Section 9 décrit le recours exclusif de chaque Partie Protégée.
10. <span class="header_2">Assurance</span>
    1. Pendant la durée de l'Accord et pendant six mois après, chaque partie maintiendra des polices d'assurance commerciale avec des limites de couverture répondant aux <span class="keyterms_link">Minimums d'Assurance</span> requis dans le BdT, le cas échéant.
11. <span class="header_2">Confidentialité</span>
    1. <span class="header_3">Non-Utilisation et Non-Divulgation.</span>  Sauf autorisation dans l'Accord, le Destinataire (a) n'utilisera les Informations Confidentielles du Divulgateur que pour remplir ses obligations ou exercer ses droits ; et (b) ne les divulguera pas à quiconque. Le Destinataire protégera les Informations Confidentielles avec au moins les mêmes protections qu'il utilise pour ses propres informations similaires.
    2. <span class="header_3">Exceptions.</span>  Les Informations Confidentielles n'incluent pas les informations que le Destinataire connaissait sans obligation de confidentialité, qui sont ou deviennent publiquement connues, reçues d'un tiers autorisé, ou développées indépendamment.
    3. <span class="header_3">Divulgations Requises.</span>  Le Destinataire peut divulguer les Informations Confidentielles dans la mesure requise par les Lois Applicables, à condition de fournir un préavis raisonnable.
    4. <span class="header_3">Divulgations Autorisées.</span>  Le Destinataire peut divulguer les Informations Confidentielles aux employés, conseillers, sous-traitants et représentants qui en ont besoin, à condition qu'ils soient soumis à des obligations de confidentialité au moins aussi protectrices.
12. <span class="header_2">Conditions Générales</span>
    1. <span class="header_3">Intégralité de l'Accord.</span>  Le présent Accord constitue l'intégralité de l'accord entre les parties sur son objet et remplace toutes les déclarations antérieures.
    2. <span class="header_3">Modifications, Divisibilité et Renonciation.</span>  Toute modification doit être faite par écrit et signée ou acceptée électroniquement. Si une clause est jugée invalide, les autres restent en vigueur.
    3. <span class="header_3">Droit Applicable et Tribunaux Compétents.</span>  Le <span class="keyterms_link">Droit Applicable</span> régira toutes les interprétations et tous les litiges. Les parties porteront tout litige devant les <span class="keyterms_link">Tribunaux Compétents</span>.
    4. <span class="header_3">Mesures Conservatoires.</span>  La violation de la Section 11 ou des droits de propriété intellectuelle peut causer un préjudice irréparable, permettant de solliciter des mesures conservatoires.
    5. <span class="header_3">Recours Non Exhaustifs.</span>  Sauf lorsque l'Accord prévoit un recours exclusif, l'exercice d'un recours ne limite pas les autres droits disponibles.
    6. <span class="header_3">Cession.</span>  Aucune partie ne peut céder sans consentement écrit préalable, sauf si le <span class="keyterms_link">Client</span> effectue une cession en cas de fusion ou de changement de contrôle.
    7. <span class="header_3">Pas de Publicité.</span>  Aucune partie ne peut annoncer publiquement l'existence du présent Accord ou d'un BdT sans l'approbation écrite préalable de l'autre partie.
    8. <span class="header_3">Notifications.</span>  Toute notification doit être faite par écrit et envoyée à l'Adresse de Notification.
    9. <span class="header_3">Indépendance des Contractants.</span>  Les parties sont des contractants indépendants.
    10. <span class="header_3">Absence de Tiers Bénéficiaire.</span>  Le présent Accord ne crée aucun droit au profit de tiers.
    11. <span class="header_3">Force Majeure.</span>  Aucune partie n'est responsable d'un retard causé par un Événement de Force Majeure.
    12. <span class="header_3">Contrôle des Exportations.</span>  Le <span class="keyterms_link">Client</span> respectera toutes les lois et réglementations françaises et européennes relatives au contrôle des exportations et aux sanctions.
    13. <span class="header_3">Anti-Corruption.</span>  Aucune partie ne prendra de mesures violant les lois anti-corruption applicables, notamment la loi Sapin II (loi n° 2016-1691 du 9 décembre 2016 relative à la transparence, à la lutte contre la corruption et à la modernisation de la vie économique).
    14. <span class="header_3">Titres et Interprétation.</span>  Les titres des sections sont donnés à titre de commodité.
    15. <span class="header_3">Signature.</span>  Le présent Accord peut être signé en plusieurs exemplaires, y compris sous forme électronique.
13. <span class="header_2">Définitions</span>
    1. **« Filiale »** désigne une entité contrôlée directement ou indirectement, à plus de cinquante pour cent (50 %).
    2. **« Accord »** désigne les présentes Conditions Générales, les Conditions Clés entre le <span class="keyterms_link">Prestataire</span> et le <span class="keyterms_link">Client</span>, et les politiques et documents référencés.
    3. **« Lois Applicables »** désigne les lois, règles, réglementations et décisions contraignantes d'une autorité gouvernementale compétente.
    4. **« Ordre de Modification »** désigne un document identifiant le BdT modifié, décrivant les modifications et approuvé par un représentant autorisé de chaque partie.
    5. **« Informations Confidentielles »** désigne les informations divulguées dans le cadre du présent Accord identifiées comme confidentielles ou devant raisonnablement être comprises comme telles.
    6. **« Page de Couverture »** désigne un document signé ou accepté électroniquement par les parties.
    7. **« Réclamation Couverte »** désigne soit une <span class="keyterms_link">Réclamation Couverte du Prestataire</span>, soit une <span class="keyterms_link">Réclamation Couverte du Client</span>.
    8. **« Matériaux du Client »** désigne les données, informations ou matériaux fournis par ou au nom du <span class="keyterms_link">Client</span> pour utilisation avec les Services.
    9. **« Événement de Force Majeure »** désigne un événement imprévisible échappant au contrôle raisonnable d'une partie (catastrophes naturelles, guerre, pandémie, actes terroristes, défaillance des services publics).
    10. **« Matériaux Préexistants »** désigne toute information, outil, matériau ou propriété intellectuelle développés ou possédés par le <span class="keyterms_link">Prestataire</span> avant la <span class="keyterms_link">Date d'Entrée en Vigueur</span>.
    11. **« Services »** désigne les services décrits dans un BdT, y compris la création de <span class="sow_link">Livrables</span> (le cas échéant).
    12. **« BdT »** (Bordereau de Travail) désigne une Page de Couverture incluant les détails commerciaux clés du présent Accord.
    13. **« Sous-traitants »** désigne les tiers ou Filiales du <span class="keyterms_link">Prestataire</span> engagés pour exécuter une partie des Services.
    14. **« Matériaux Tiers »** désigne toute information, outil, matériau ou propriété intellectuelle appartenant à un tiers.
    15. **« Données d'Utilisation »** désigne les données et informations sur la fourniture, l'utilisation et les performances des Services.
